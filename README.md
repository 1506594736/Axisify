# Axisify

Axisify 是一个 Blender Geometry Nodes 插件，用于从开放曲面生成实体，并把接近坐标轴的侧壁对齐到 X、Y、Z 轴。

插件只提供 Geometry Nodes 修改器工作流：参数可以在修改器面板中实时调整，不会自动生成或烘焙新物体。

## 下载

从 GitHub 下载最新版本：

https://github.com/1506594736/Axisify/archive/main.zip

## 安装

1. 打开 Blender，进入“编辑 → 偏好设置 → 插件”。
2. 点击右上角菜单，选择“从磁盘安装”。
3. 选择下载的 ZIP 文件。
4. 勾选 Axisify 启用插件。

升级插件后建议重启 Blender，确保旧版本的面板和节点组已经卸载。

## 使用

Axisify 需要**开放曲面**作为输入。闭合网格没有边界边，插件会拒绝执行，避免生成两个重叠的壳体。

1. 选中一个网格物体，并切换到物体模式。
2. 在 3D 视图按 `N`，打开 Axisify 标签页。
3. 调整参数并点击“作为修改器（可实时调整）”。
4. 在物体的修改器面板中继续调整 Axisify 参数。

插件会在物体上创建一个名为 `Axisify` 的 Geometry Nodes 修改器。重复点击按钮会复用已有 Axisify 修改器，并同步面板中的当前参数，不会叠加多个 Axisify 修改器，也不会删除用户已有的其他修改器。

## 参数

### 取轴方式

| 参数 | 说明 |
|---|---|
| **取轴方式** | 自动模式为每个区域选择最接近的坐标轴；固定模式使用指定轴。 |
| **固定轴** | 固定模式下使用的轴，可选 `±X`、`±Y`、`±Z`。 |
| **吸轴角度** | 原始法线与目标轴的夹角小于此值时才吸附。超过容差会保持原始方向。 |

### 实体化与保护

| 参数 | 默认值 | 说明 |
|---|---:|---|
| **厚度** | 0.01 | 实体化偏移距离。 |
| **对齐到轴** | 开 | 关闭后保留原始法线方向，只执行偏移和实体化。 |
| **厚度钳制** | 0.9 | 按局部曲率半径限制厚度，降低弯曲区域翻转和自交的风险；设为 0 可关闭。 |
| **最大厚度** | 0 | 对实际厚度设置硬上限；0 表示不限。 |
| **合并顶点** | 0 | 以“厚度 × 此值”为距离进行额外焊接。通常保持 0。 |

插件当前不提供 Blender Solidify 的“向内/居中/向外”和“均匀厚度”选项。Geometry Nodes 使用自身的法线偏移算法；在弯曲区域，严格轴对齐与处处完全等厚通常无法同时满足。

## 工作原理

插件读取输入曲面的法线，将满足吸轴容差的法线替换为目标坐标轴方向，然后沿该方向生成内层和边界侧壁。最后合并几何并按需要焊接顶点。

固定轴模式同样遵守吸轴角度：超过容差的区域保持原始法线，不会强制切换到指定轴。

## 已知限制

- 只支持开放曲面。闭合网格会被拒绝。
- 侧壁严格轴对齐后，弯曲区域的内外边界长度可能不同，这是几何约束产生的结果。
- 厚度大于局部曲率半径时仍可能产生自交；可使用“厚度钳制”和“最大厚度”降低风险。
- 曲率半径估计依赖输入网格的离散分辨率。细分过密或法线噪声较大的网格，建议使用“最大厚度”作为明确上限。
- 插件只使用 Blender 自带的 `bmesh`、`mathutils` 和 Geometry Nodes 功能，不需要额外安装 Python 依赖。
